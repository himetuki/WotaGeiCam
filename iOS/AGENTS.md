# iOS 移植约束

本目录是 Android → iOS 的独立原生移植工程。用户已授权自主推进及每步本地提交；禁止推送。主工作区分支 `port/ios-20261115`，只允许新增/修改 `iOS/` 内移植成果，不改写既有提交，不修改仓库其他文件。

## 全局约束（用户原文）

- 不修改 Android/ 与 HarmonyOS/ 下的任何文件。
- 不把 Android 的 GL/GLSL 代码直接翻译进 Swift/Metal；算法思路可参考，代码必须重写。
- 不假设 iOS 相机 API 与 Camera2 语义等价；每个参数映射必须有设备支持判断与降级路径。
- 不引入 Android 中不存在的隐式媒体库行为；文件命名与目录约定与 Android 对齐。
- iOS UI 以 iOS 原生相机/照片应用惯例为优先，不以“和 Android 看起来一样”为目标；不引入 Material 组件。
- AI 站位功能一律不实现、不移植、不保留占位接口。
- 真机能力验证（如某机型 format 是否支持 1/24）不写入自动验收条件，改为在交付物中列《人工验证清单》。
- 所有权限 Info.plist 描述必须具体说明 WOTA 艺录制用途，禁止占位文案。

## 工程与证据纪律

- 以 UIKit + AVFoundation 重写基础录制与参数页，最低源码兼容目标为 iOS 10（iPhone 5/6）；SwiftUI 只能作为更高系统的可选层，不能进入基础路径。图像后端按能力选择 OpenGL ES 2/3、Metal 或 CPU，Metal 不能作为老设备唯一后端。不得引入未在子任务声明的第三方依赖。
- 遵守主代理下发的文件写入所有权；只读参考源代码前读取适用说明与领域知识索引。
- 不读 `.env`、密钥、账户、签名等隐私配置；所有临时文件/截图/构建产物在工作区内本目录，不以 C 盘为中转。
- 先读文件再编辑；不修改其他并行代理拥有的文件；由主代理核验并提交，子代理不得自行操作 Git 写状态。
- 每次回报严格四段：已完成项 / 未完成项 / 阻塞项 / 证据（命令与输出摘要）。静态检查、Swift单测、Apple编译、模拟器交互、真机验证是不同证据，分别记录，禁止互相冒充。
- 用户于2026-11-15修订：只移植、编译、打包，不使用模拟器、不编写或执行测试，不要求UI截图。构建必需的源清单/工程/plist/包结构检查仍执行。无签名包必须源自真实设备构建，不伪造 app/ipa。
- 同步入口：[UPSTREAM_SYNC.md](UPSTREAM_SYNC.md)。路线图：[docs/ROADMAP.md](docs/ROADMAP.md)。
